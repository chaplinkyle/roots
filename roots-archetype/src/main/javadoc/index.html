Roots application generator

This Maven archetype contains project templates rather than a Java API. Its sources artifact contains the template files. The generated application imports the API from com.chaplin.roots:roots-core; use that artifact's Javadoc for Java types.

The required rootsVersion property selects the framework version. The archetype metadata supplies the matching version by default. Supply a project group ID, artifact ID, version, and Java package when generating an application.

See the generator guide for commands and the release guide for using a staged artifact bundle.
