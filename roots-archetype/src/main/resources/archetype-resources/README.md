```shell

```

annotated actions, authorization policies, and their current DOM event bindings.

```shell
mvn package
java -jar target/${artifactId}-${version}.jar
```

Add routes beneath `src/main/java/${packageInPathFormat}/pages` using `Page.java` and `Layout.java`.
Customize the included root `pages/NotFound.java` and `pages/ErrorPage.java` for
live production 404 and safe 500 experiences.
Reusable UI implements `Component`; browser events call methods annotated with `@ServerAction`.

compilation and packages their route manifest in the application JAR. The `/about`
page is statically generated by the configured Roots Maven plugin during packaging;
use `@Prerender` only for public, deterministic pages.
